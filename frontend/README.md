# WaveTime Frontend

Vue SPA для клиентского и админского интерфейсов WaveTime.

## Требования
- Node.js 20+
- Запущенный backend на `http://127.0.0.1:8080`

## Установка и запуск
```bash
cd frontend
npm install
npm run dev
```

Dev URL: `http://127.0.0.1:5173`.

## Сборка
```bash
cd frontend
npm run build
npm run preview
```

## Маршруты
- `/` - главная страница
- `/login` - вход
- `/register` - регистрация
- `/schedule` - расписание и бронирование (только авторизованные)
- `/app` - личный кабинет (только авторизованные)
- `/admin` - админка (только роль `admin`)

## Поведение авторизации
- Если пользователь не авторизован, закрытые маршруты редиректят на `/login`.
- Если пользователь авторизован и открывает `/login` или `/register`, выполняется редирект:
  - админ -> `/admin`
  - клиент -> `/app`
- В хедере показываются профиль пользователя и кнопка выхода.

## Интеграция с backend
- Все запросы идут на `/api/...`.
- Vite proxy пробрасывает их в `http://127.0.0.1:8080/...`.
- Это позволяет не настраивать CORS в dev-режиме.
